# Reverse Array

This program reverses the elements of an array and displays the result.

## Features

* Takes array elements from the user
* Displays the elements in reverse order
* Uses a simple loop

## Technology Used

* C

## Concepts Used

* Arrays
* For loop
* Array traversal
* Variables

## Sample Output

Enter the number of elements: 5
Enter 5 elements:
10 20 30 40 50
Reversed array: 50 40 30 20 10
